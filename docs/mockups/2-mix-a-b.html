Mixing pulse-and-glow with glitch: how much glitch?

Both run on the same fake beat (100 BPM). Every 4th beat is a "big hit", standing in for a drop or a loud kick in a real song.

1. Glow every beat, glitch only on big hits

Mostly calm pulse and glow. The glitch is saved for drops and heavy kicks, so it feels like an event when it happens.

2. Light glitch every beat, heavy on big hits

Every beat gets a small colour split along with the pulse, and big hits glitch hard. Busier, closer to the Instagram post.
